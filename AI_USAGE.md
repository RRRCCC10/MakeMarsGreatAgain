# AI / SI Usage Disclosure

## Game code

We used AI tools to assist with GDScript development and debugging. This included suggesting implementations, generating portions of code, and helping troubleshoot issues.


## Pixel-art assets

The game uses pixel art drawn by our team, AI-generated sprites, and sprites that combine AI generation with manual editing.

## Presentation

The team developed the presentation content and created the original cover design. We used AI to help rework the cover visuals, then manually edited and finalized the result.
